# Galaxy Sofas Websites

Premium Angular 22 static + SSR-ready luxury furniture website for **Galaxy Sofas**.

## Stack
- Angular 22 standalone architecture
- Signals-first state and component APIs (`signal`, `computed`, `linkedSignal`, `resource`, `model`, `input`, `output`)
- Zoneless change detection
- Tailwind CSS 4
- Angular CDK + Angular animations
- SSR-ready routing and SEO metadata

## Included Pages
Home, About, Products, Product Details, Categories, Collections, Why Galaxy Sofas, Manufacturing Process, Custom Furniture, Gallery, Interior Inspiration, Testimonials, FAQs, Blog, Blog Details, Contact, Store Location, Privacy Policy, Terms, and 404.

## Run
```bash
npm install
npm run build
npm test -- --watch=false
npm start
```
