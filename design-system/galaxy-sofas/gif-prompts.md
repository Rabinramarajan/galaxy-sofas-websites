## Technical notes

- **Format order:** WebM (animated) → MP4 → GIF; GIF only as last-resort fallback (size).
- **Frames:** keep ≤ 96 frames for small loops; 8s at 30fps = 240 frames — prefer 24fps.
- **File size budget:** hero/banner loops ≤ 1.5MB; background ambience ≤ 600KB; logo shimmer ≤ 250KB.
- **Reduced motion:** swap all loops for a static poster image.
